# Windows Easy Backup v0.2.0

## 本版重点

v0.2.0 将应用从单一备份页推进为 Windows 本地文件资产工作台基础架构：

- 新增 SQLite Catalog：扫描目录、建立文件索引、读取基础时间/大小/类型/MIME，并支持增量 size/mtime 判断。
- 新增 Planner → Preview → Executor 链路：支持 rename / move / copy 计划、Windows 文件名校验、目标冲突自动编号和执行前源文件变化检查。
- 新增 Operation Journal 与基础 Undo：rename / move 成功后可从“历史”页撤销；原位置冲突时不覆盖文件。
- 新增统一 Task Engine 事件：扫描、整理、备份使用 `task-progress`、`task-completed`、`task-error`。
- 新增“最近 / 文件 / 整理 / 历史 / 设置”工作台 Shell，重复项、恢复、规则编辑器按版本规划明确标注。
- 保留原有备份能力：Known Folder、自定义源、微信、QQ、Chrome、Edge、SSH、VS Code、过滤、空间预检、取消、ZIP、7Z、报告和通知。

## 安全边界

扫描、索引和预览不会修改源文件。整理应用前会重新检查 size / mtime；跨盘移动遵循 Copy → Verify → Delete Source。应用不上传文件，默认不永久删除。
