# Windows Easy Backup v0.5.0

## 本版重点

- 完成 PRD v0.2–v0.5 的本地文件工作台链路：Catalog、Task、Planner、Preview、Executor、Journal 和 Undo。
- 新增规则编辑器：AND / OR / NOT 条件、移动/复制/重命名/标签/忽略动作，以及日期、序号、Hash、图片/EXIF/音频 metadata 命名变量。
- 新增完全重复与相似图片分析：BLAKE3 Hash Cache、感知 Hash、汉明距离和默认移至 Windows 回收站的安全计划。
- 新增 Backup Job、Snapshot、Manifest、增量备份、快速/完整 BLAKE3 校验、原位置/指定目录恢复和显式保留清理。
- 保留原有 Known Folder、自定义源、过滤、空间预检、取消、ZIP、7Z、报告和通知能力。

## 安全边界

扫描、索引、分析和预览不会修改源文件。所有整理、恢复和重复清理都先生成预览计划；执行前重新检查源文件状态。普通冲突默认自动编号，替换不会静默覆盖，重复项进入 Windows 回收站。应用不上传文件、不要求登录。

PRD v0.6 的监控文件夹/托盘/定时任务，以及 v0.7 的 PDF/DOCX 文本、OCR、智能分类仍未纳入本版。
