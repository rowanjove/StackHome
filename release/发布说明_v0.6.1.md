# 归栈 v0.6.1

这次更新为软件建立了新的中文产品身份，并完成图标、桌面 Shell 与核心页面的整体重构。功能边界不变：文件留在本机，改动前先预览，操作尽量可撤回。

## 新品牌

- 产品名由 Windows Easy Backup / Windows Local File Workspace 调整为“归栈”，副标题为“本地文件工作台”。
- 新图标以叠放文件归入档槽为核心轮廓，提供 Windows ICO 与多尺寸 PNG 资源。
- 采用炭墨、暖纸、陶土橙配色，以及纸张、索引签和档案柜式排版。
- 去除蓝紫渐变、玻璃拟态、悬浮圆角卡片和 AI 魔法类符号。

## 界面调整

- 重构侧栏品牌区、导航状态、窗口标题区和底部任务中心。
- “最近”页改为编辑部式入口，突出本机处理、先看后改、留有退路三项原则。
- 文件列表、备份面板、表格和表单统一为紧凑的档案工作台样式。
- 修复 1024×680 最小窗口下的横向溢出。

## 兼容说明

- 应用标识 `top.rowanjove.windows-easy-backup` 保持不变，避免破坏既有升级识别。
- 本机配置和数据库继续使用既有应用数据目录，已有数据无需迁移。
- 旧版发布文件与校验记录继续保留。
