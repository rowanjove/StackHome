# Windows Easy Backup v0.1.0

## 该下载哪个？

- **Windows Easy Backup - Portable (Win10-11) v0.1.0.exe**
  - 适合 Windows 10 / 11
  - 单个文件，下载后双击即用

- **Windows Easy Backup - Installer (Compatibility) v0.1.0.exe**
  - 适合老机器
  - 走普通安装流程，兼容性更稳

## 本版能力

- 自动识别桌面、下载、文档、图片、视频、音乐目录
- 扫描文件数量和总大小
- 异步备份、实时进度、取消任务
- 生成备份报告和日志

## 选择建议

如果你用的是较新的 Windows 10 或 Windows 11，优先下载便携版。

如果便携版打不开，或者你想走标准安装流程，就用安装版。
