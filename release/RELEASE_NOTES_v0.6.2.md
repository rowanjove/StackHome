# StackHome v0.6.2 / 归栈 v0.6.2

StackHome is the English product name for 归栈. This release completes the public open-source package without changing the local-first safety model or the existing upgrade path.

StackHome 是“归栈”的英文产品名。本次更新补齐公开开源发布所需的中英文说明、真实界面截图、许可证和 Windows 下载包，同时保持既有数据兼容与本地优先的安全边界。

## Changes / 更新内容

- Unified the application, window, tray, notification, report, package, and repository branding under StackHome.
- Added independent Chinese and English README pages with direct capability, safety, compatibility, and build information.
- Added an MIT license and a real desktop screenshot.
- Renamed Windows artifacts to stable ASCII filenames for direct links and automated tooling.
- 保留原应用标识和既有本地数据目录，旧版本用户无需迁移数据。
- 文件整理仍须先生成计划并预览；跨盘移动仍执行 Copy → Verify → Journal → Delete Source。
