# Windows Easy Backup v0.6.0

## 本次更新

- 新增 Watch Folder：监控目录发现稳定的新文件后生成 Planner 计划。
- 新增自动规则：只有用户明确指定规则并开启“自动应用”才会执行移动；默认仍只生成计划。
- 新增定时备份：按备份页当前来源、目标和选项在后台执行，任务进度继续进入 Task Center。
- 新增 Windows 托盘：可从托盘打开工作台，设置关闭窗口时最小化到托盘。
- 完善图片 EXIF GPS 读取、视频 MP4 时长/宽高/创建时间读取。
- 目标文件与源文件内容相同时，计划标记为 duplicate 并跳过，避免产生重复副本。
- 大目录预览改为窗口化表格，并补齐 Ctrl+F、Ctrl+A、Esc、Enter 与可见焦点交互。

## 安全边界

- 自动化配置只保存在应用本地数据目录。
- Watch Folder 的自动应用仍经过 Planner；目标冲突、源状态变化和执行错误沿用现有保护。
- 定时备份依赖工作台进程持续运行；启用关闭到托盘可让它在后台继续运行。
- 本版本不上传文件、不要求账号，也不提供默认永久删除。
